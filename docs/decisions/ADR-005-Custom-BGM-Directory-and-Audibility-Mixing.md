# ADR-005: 自定义背景音乐库与人声避让弱音混音规范

## 状态 (Status)
**Accepted (已采纳实施)**

## 日期 (Date)
2026-10-11

## 背景与上下文 (Context)
视频合成中背景音乐（BGM）对氛围烘托至关重要，但在短视频实操中经常出现严重影响用户体验的问题：
1. **音乐喧宾夺主**：BGM 音量过大，盖过解说人声，导致观众听不清核心关键信息。
2. **音乐源固化单调**：硬编码单一固定音频，所有条目千篇一律。
3. **外部音频格式杂乱**：用户可能使用不同采样率、声道的 MP3 文件，需要系统自动循环对齐和尾部平滑淡出。

## 架构决策 (Decision)

### 1. 设立专用根目录 `backgroup_music/`
- 在项目根目录下建立专门的背景音乐库文件夹 `backgroup_music/`。
- 允许用户放入任意格式规范的 `.mp3` 音乐文件（系统内置了 `01_country_music.mp3`, `02_NastelBom.mp3`, `03_AbsoluteSound.mp3`）。
- 在合成脚本执行时，系统自动扫描该目录；若未通过 `--bgm` 手动指定，则自动从中随机挑选一首，确保各条目视频的听觉多样性。

### 2. 精确的弱音音量系数 (-20dB) 与平滑包络
- 将背景音乐轨音量倍率限制在 **`0.08 ~ 0.09`（约 -20dB 衰减）**。
- 背景音乐定位为“纯空气感与节拍衬底”，任何频段都不对云泽人声（解说口播）构成声学压制。
- 时间轴循环与淡入淡出：
  - 若音乐短于视频总长，自动循环（Loop）；
  - 开头设置 $1.0\text{s}$ 平滑淡入（`audio_fadein(1.0)`）；
  - 结尾设置 $2.0\text{s}$ 自然淡出（`audio_fadeout(2.0)`），与黑场和定格金句协同结束。

## 备选方案评估 (Alternatives Considered)

### 备选方案 A：动态侧链压缩 (Ducking)
- **分析**：根据人声振幅实时压低音乐、人声停顿时间恢复音乐。
- **缺点**：在 Python 端做音频样本级 Ducking 计算开销大，且容易导致短视频背景音乐产生“呼吸起伏喘息感”，听感反而不适。
- **结论**：**否决（采用全局稳定 -20dB 弱衬底方案更为纯粹舒适）**。

## 实施后果与收益 (Consequences)
- 人声解说极其清脆清晰，同时有柔和的律动烘托。
- 用户扩展音乐极为方便，只需往 `backgroup_music/` 拖入 MP3 即可，无需修改任何代码配置。
