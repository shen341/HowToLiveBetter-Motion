# ADR-006: AI 语义理解自主选风与多模态风格调度

## 状态 (Status)
**Accepted (已采纳实施)**

## 日期 (Date)
2026-10-11

## 背景与上下文 (Context)
在项目初期，视觉风格主要依靠硬编码规则（如第 01 章统一绑定吉卜力风格）。但在实际应用中，全书 677 条生活建议跨越了极宽广的知识领域与情感基调：
- 有些条目是温馨生活好习惯（如饭后百步走、正确刷牙）；
- 有些条目是严肃法律威慑与防骗（如借贷担保、兼职诈骗、网络谣言）；
- 有些条目是硬核生理机制与认知拆解（如深睡眠周期、注意力余量、咖啡因代谢）；
- 有些条目是消费陷阱与强烈痛点（如自动续费、沉没成本、借钱破防）；
- 有些条目是现代都市孤独感与心理调适（如独处、应对职业瓶颈）。

如果一律使用同一种吉卜力水彩风，不仅视觉审美疲劳，更会因“画风与题材语义脱节”（如用温馨动漫风画严重的经济犯罪）而削弱内容的警示力与说服力。

## 架构决策 (Decision)

### 1. 扩充开源 `huashu-art-motion` 风格卡配方库
在 `src/prompt_builder.py` 中规范定义 7 种高表现力艺术风格卡：
- `25_ghibli`：吉卜力暖调手绘风（温馨治愈守护）
- `w1_whiteboard`：极简手绘白板风（思维导图、避坑防骗与理性决策）
- `y1_kurzgesagt`：Kurzgesagt 扁平科普风（纯净几何与生理机制拆解）
- `13_pop`：利希滕斯坦波普艺术风（本戴点美漫与强烈反常识痛点）
- `24_hopper`：霍珀美国现实主义风（强烈斜射光影与都市沉思）
- `17_ink`：新中式东方水墨风（留白与处世哲学心境）
- `14_pixel`：8-Bit 像素复古游戏风（打怪升级与微习惯打卡）

### 2. 赋予大模型（`muse-spark`）导演级自主选风决策权 (`--style auto`)
- 将完整风格菜单、适用场景与美学特征注入提示词。
- 允许大模型在阅读条目的说人话要点、权威数据与情绪基调后，**自主权衡裁决最匹配的 `art_style_id`，并在分镜 JSON 中输出一句话选风理由 `art_style_reason`**。
- 大模型自动将该选定风格的核心关键词基石（Keywords）织入每个分镜的 `image_prompt` 尾部，确保生图模型精准遵循该画风。

### 3. 三种调度模式解耦
在 `02_ai_generator.py` 中引入命令行参数 `--style`：
- **`--style auto`（默认）**：AI 语义理解自主决策。
- **`--style chapter`**：遵循所属章节大类分类映射，保证同一章节系列的视觉品牌一致。
- **`--style <id>`**：如 `--style w1_whiteboard`，人工强制指定，方便针对同一篇文案进行多风格 A/B 测试。

## 备选方案评估 (Alternatives Considered)

### 备选方案 A：维持单一固定画风
- **缺点**：无法契合多变的内容主题，视频流水线缺乏表现力，很快令观众审美疲劳。
- **结论**：**否决**。

### 备选方案 B：仅靠正则关键字匹配写死规则
- **缺点**：规则难以覆盖自然语言的多变语义与情感色彩，易误判。
- **结论**：**否决（大模型天然擅长语义理解与情绪推断，交给 LLM 决策是最优解）**。

## 实施后果与收益 (Consequences)
- 经实测，大模型对法律防骗条目自主选择了 Vox 剪报风、对注意力机制条目自主选择了 Kurzgesagt 扁平风、对健康守护条目自主选择了吉卜力风，准确率与表现力极高。
- 用户保留完全的控制权，既可全自动批处理，亦可按需精细化指定。
