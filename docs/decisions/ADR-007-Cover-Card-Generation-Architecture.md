# ADR-007: 竖屏高辨识度专属封面卡片自动生成架构 (Cover Card Generator)

## 状态 (Status)
**Accepted (已采纳实施)**

## 日期 (Date)
2026-10-11

## 背景与上下文 (Context)
在小红书、抖音、微信视频号等现代短视频分发平台上，**视频封面（首图）直接决定了 60% 以上的初次点击率（CTR）**：
1. **默认首帧缺陷**：如果直接截取视频第一帧作为封面，通常处于镜头平移、叠化淡入或人物微动过程，画面对比度低、缺乏大字提炼，难以在信息流推荐页中吸引用户停留。
2. **缺乏权威硬核标签**：本项目核心竞争力在于“高性价比、权威循证、低成本”，如果不以醒目卡片式标签直观呈现“证据等级 A 级”、“0 成本”、“降 60% 死亡率”，内容公信力大打折扣。
3. **字体与平台 Emoji 兼容性痛点**：操作系统默认字体在绘制 Emoji 时极易渲染为白框方块（Tofu box `□`），破坏卡片美观度。

因此，亟需在流水线中建立自动化的高清竖屏封面卡片生成引擎。

## 架构决策 (Decision)

### 1. 独立封面渲染引擎 (`src/cover_generator.py`)
打造专用的 `CoverGenerator` 引擎，输出标准 1080×1920 竖屏高对比度首图：
- **视觉层级架构 (Visual Hierarchy)**：
  - **顶部品牌胶囊**：标注《高性价比人生指南》专栏名与证据等级徽章；
  - **黄金上部 Hero 大字标题**：38~56pt 超大加粗标题，支持长短句智能排版与两行折叠；
  - **引人入胜的痛点钩子 (Hook)**：提取“日常最易忽略的致命细节”引出核心认知颠覆；
  - **3 维度权威收益与成本信息条 (Badges)**：
    - 权威等级（如“证据等级 A 级”）
    - 执行代价（如“0 元成本 / 2 秒极简”）
    - 核心收益（如“致死风险降 50%”）
  - **背景柔和暗角与毛玻璃垫片**：自适应第一幕原画或风格基底色，确保文字在任何背景下 100% 清晰可辨。

### 2. 规避 Emoji Tofu 乱码设计
系统废弃不可控的系统 Emoji，改用通用 Unicode 几何符号（`●`、`◆`、`★`）及 Pillow 原生贝塞尔圆角矩形胶囊，确保在 Windows/Linux/macOS 跨平台环境下一致的高清呈现。

### 3. 流水线两级全自动触发与独立重制
- **素材阶段（`02_ai_generator.py`）**：在素材生成完毕后，自动渲染落盘至 `output/raw_assets/{entry_id}/cover.png`；
- **成片阶段（`03_video_assembler.py`）**：在合成渲染完成后，自动同步交付至 `output/final_videos/{clean_name}_cover.png`；
- **独立 CLI**：支持创作者单独针对某个条目重新排版渲染封面：
  ```powershell
  python -m src.cover_generator --entry-id 01_001
  ```

## 备选方案评估 (Alternatives Considered)

### 备选方案 A：依靠视频剪辑软件手动截图贴字
- **缺点**：无法适配 677 条生活指南的大规模自动化工业流水线，人工排版耗时极长。
- **结论**：**否决**。

### 备选方案 B：直接调用生图模型绘制带文字的封面
- **缺点**：当前生图大模型（Diffusion / Imagen）生成大段复杂中文汉字极易出现错别字、笔画粘连或扭曲变形，无法保证严谨科普的可读性。
- **结论**：**否决（采用大模型生成无文字高清底图 + Pillow 代码级排版字体是最稳定工业解）**。

## 实施后果与收益 (Consequences)
- 实现了真正的“一键输出发布三件套”：`MP4 视频 + Cover PNG 封面 + SRT 外挂字幕`。
- 保证了系列化视频的视觉品牌辨识度与点击转化率。
